Script output builders write equations, inline math, struck and new-tab text runs, and tables with header and stub cells, column alignment and widths, merged cells, horizontal rules, a natural width and a caption. A table's `table-border-horizontal` class draws rules between rows only. A hidden caption on a figure or code block takes no number and no line in a list of contents.
