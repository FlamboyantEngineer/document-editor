Lists the table entries of the context menu at its top level, makes the row and column grips opt-in with `tableHandles`, lets header cells cite footnotes, gives a marker inserted in a comment or suggestion its marks, and shows a footnote's other part on double click without moving the caret. The reference stylesheet aligns figure captions, labels linked code and draws one pixel table borders.
