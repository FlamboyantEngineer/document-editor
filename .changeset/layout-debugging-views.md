Layout debugging shows each page's paper, content, header, footer, used, stacked and free lengths and the pixel ratio; outlines each block and region with its type, height and overflow; adds a tooltip for each block, a resizable debugging pane that shows the measuring view or the pages' markup, a shortcut that cycles the debugging modes (`onDebugChange`), and a layout trace (`debug.trace`).
