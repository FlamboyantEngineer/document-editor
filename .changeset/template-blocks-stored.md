A template block now stores what its markup rendered as its own blocks, which the pages lay out and split like any other content, instead of a `renderedHtml` attribute drawn by a node view and measured as drawn. After any change to the stored texts or to a template block, the writer's own, another writer's, a server's or a replayed one, an editor that edits directly renders each block that holds anything else, out of the undo history; two editors who render at once in a room settle on one copy. Opening a document, typing, reading and suggesting render nothing. The writer cannot edit inside a template block, and Backspace and Delete beside one select it whole. `createDynamicTemplates` takes `{ enabled }`; `renderTemplateBlock` gives the blocks as a ProseMirror fragment; `renderTemplateBlocks(tr, document)` renders a document's template blocks; `refreshDynamicTemplates` is removed. Markdown writes a template block's stored blocks. The stored `templateBlock` holds its blocks as `content`.
