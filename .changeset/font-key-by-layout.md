The layout inputs key no longer changes when the same served fonts arrive in another order of families, with a duplicate face, or with a family named in another letter case or quoting; it still follows the order of a family's faces and the family served first. The key's version moves to 4, so a key recorded before differs. An inline node sized by a layout rule keeps its marks, so inline code around it is measured as drawn, and the viewer mounts where the browser takes no document as an observer's root.
