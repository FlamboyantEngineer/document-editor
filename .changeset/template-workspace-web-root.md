The template workspace takes `isRoot`, for a template that inherits nothing, not even the base template, and has no parent row, and `isNameReadOnly`, for a template whose name is shown but not edited. For the web layout the template editor also leaves out paragraph numbering, footnotes, references, change bars and contents, and edits the margins in pixels. The references settings hold a Format card, then a card of links, with a note on the tokens a format may use; `referenceTypes` (on the template editor and the workspace) adds the host's own reference types.
