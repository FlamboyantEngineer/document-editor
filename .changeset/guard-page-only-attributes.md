A guarded room refuses every attribute only the pages set unless it holds its whole value: the part of a split block, a list item continued from an earlier page, a continued container's placeholder paragraph, a continued code block and its first line number, and a contents block's entry range and title, so a change of the part a block is is never counted as a decision. A deletion that covers a whole figure or layout section none of whose text would take the writer's mark is not suggested, since nothing would name its writer.
