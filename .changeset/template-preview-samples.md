The template preview shows nested lists, a figure, a second footnote, a table and a code block long enough to continue on the next page, and a paragraph per kind of change. `templatePreviewPrevious(preview)` gives the older version to compare the preview with, so it shows an insertion, a deletion, a modification and a formatting change. `TemplatePreviewText` gains `secondFootnote`, `subItem`, `figure` and `changes`.

Select All in a header, footer or footnote area selects that region's text alone.
