Code blocks number every line by default (`lineNumbers`), with numbers that follow wrapped lines, and a press beside the code puts the caret in it. A code block inserted over a selection takes exactly the selected text. Inline code moves from the marks group into the code menu, which can delete a run of it; the language menu names each language (`codeLanguageNames`) and adds Java. The linked code dialog shows an example address and previews the code numbered from its first line in its file. Math that does not typeset shows `invalidMath` text with the renderer's message as its tooltip, and the math dialog gains a sheet of common math and a link to a full reference (`MathLabels`).
