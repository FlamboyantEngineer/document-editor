Which code shows a gutter of line numbers is the template's `styles.codeBlock.lineNumbers` (`all`, `linked` or `none`; `all` in the base template), document-level only, and the template editor has a Line numbers row for it. The editing plugins' own `lineNumbers` option is removed, so every view of a document lays its code out alike.
