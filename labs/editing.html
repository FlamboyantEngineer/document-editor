Editing

Edit the pages with the keyboard. Mod-B, Mod-I and Mod-U format text, Mod-Shift-1 to Mod-Shift-6 make headings, Mod-Shift-8 and Mod-Shift-7 make lists, Tab nests a list item, Mod-Alt-Enter starts a new page and Mod-\ clears formatting. Backspace at the start of a page joins the text across the page break. Every new block gets its own id.

Caret in the block with id none.
