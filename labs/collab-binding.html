Spike: collaboration binding

Two people edit one document through a collaboration-tools room server running in this page. Each editor holds the whole document, without pages, through the library's own Yjs binding. Undo (Mod-Z) undoes only that person's changes, and each editor shows the other person's caret. Take one editor offline, edit both, and bring it back.
