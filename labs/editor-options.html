Editor options

Each option a host sets on the editing, the schema and the editor, with a control. Set a content limit and type past it, or let a collaborator take the document past it; keep a paragraph after a section's last table; turn the typing shortcuts off by group; keep tables whole on a page; show the figures' assets as of another time; approve a paragraph so it cannot change; open a document with broken element ids; and drop the connection before a dialog opens. The status bar's first item is the host's own, drawn only when the block at the caret changes type. The dropped connection is a service worker, which stays registered for this address and passes every other request through.
