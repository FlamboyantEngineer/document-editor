# Decision record

Decisions the owner took on 2026-11-11 for the work that makes this library a full replacement for a host's existing document editor. They are written in the library's own terms. Each entry gives the decision and what it means for the library; the specs say how it is built. A decision changes only by a new entry that names the one it replaces.

There are no stored documents, templates, versions or rooms to keep. Until the owner switches the first host over, the stored format, the layout model and the API may change without upgrade steps (D11).

| #   | Topic                                      | Decision                                                                                                                                                                                                                                                     | Consequence for the library                                                                                                    |
| --- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| D1  | Character-level contributor provenance     | Every local insert carries a contributor mark, for a person or an automated session.                                                                                                                                                                         | Contributor marks on runs, and a contributors pane in the shell.                                                               |
| D2  | Script block and embed ordinals            | No stored host markup needs matching.                                                                                                                                                                                                                        | The library keeps its own script block markup and ordinals, and documents the free ordinals hosts may use for their own nodes. |
| D3  | Persistence                                | A document opens in one of two modes, chosen at mount: room mode (a shared room on a room server) or store mode (the documents adapter).                                                                                                                     | Two session modes behind one session interface.                                                                                |
| D4  | Keymap defaults                            | Library defaults, plus Mod-' and Mod-; for subscript and superscript, Mod-Alt-L for math, Mod-Alt-S for a script block, Mod-Shift-K to copy a content link and Enter at a gap cursor. Mod-Alt-F stays footnote.                                              | Hosts remap keys through `shortcuts`.                                                                                          |
| D5  | Editing and pagination architecture        | A canonical whole-document state takes every edit and carries the realtime binding. A read-only paged projection is the only rendered surface, and a hidden measuring view measures blocks. Pages drawn as decorations on one view stay an option for later. | The engine moves off the paged state; a spike first checks input and selection routing between the two documents.              |
| D6  | Where the realtime binding lives           | In the library's `./collab` subpath, with `@y/y` as an optional peer dependency. The library never depends on a room server package.                                                                                                                         | A new `./collab` entry.                                                                                                        |
| D7  | Section names                              | No legacy names to keep.                                                                                                                                                                                                                                     | The library's section name rule stays.                                                                                         |
| D8  | Pagination parity with earlier output      | No earlier printed output to match.                                                                                                                                                                                                                          | The library's pagination rules stand; the regression labs decide.                                                              |
| D9  | Blank section numbering                    | No legacy data.                                                                                                                                                                                                                                              | The library's numbering semantics stay.                                                                                        |
| D10 | Section restart semantics                  | A section restart applies to headings and paragraphs.                                                                                                                                                                                                        | Library behaviour stays.                                                                                                       |
| D11 | Format freeze                              | The stored format freezes when the owner switches the first host over.                                                                                                                                                                                       | Golden files now; format-version upgrade steps only after the freeze.                                                          |
| D12 | Pasting from word processors               | Pasted content is cleaned to the full schema. Revision and comment markup in the clipboard never becomes suggestion or comment marks.                                                                                                                        | One paste pipeline with registered filters.                                                                                    |
| D13 | Reference and footnote places              | Strict places, and paste repairs content that lands outside them.                                                                                                                                                                                            | Paste filters for references and footnotes.                                                                                    |
| D14 | Template pinning                           | A document pins its template's id and revision. An old version renders with the template it pinned. A document moves to a newer template revision only on an explicit update, which reports the drift.                                                       | The stored file carries the pinned template revision.                                                                          |
| D15 | Typing before the first sync               | Editing starts at once from a cached room state. With no cache, the editor stays read-only until the first sync, so a fresh client never creates content the room's seed would duplicate.                                                                    | The session resolves the editing mode from the cache and the sync state.                                                       |
| D16 | Host node views while measuring            | The measuring view uses the same node views as the projection.                                                                                                                                                                                               | Follows from D5.                                                                                                               |
| D17 | Page status                                | The status bar shows the page in view.                                                                                                                                                                                                                       | Status bar page item.                                                                                                          |
| D18 | Suggestions that carry only an element id  | No legacy data.                                                                                                                                                                                                                                              | None.                                                                                                                          |
| D19 | Comments and suggestions on locked content | Locked content takes comments only.                                                                                                                                                                                                                          | Suggesting is refused inside an edit lock.                                                                                     |
| D20 | Formatting while suggesting                | Formatting changes are tracked as suggestions.                                                                                                                                                                                                               | Format-change marks, decided by the same policy as insertions and deletions.                                                   |
| D21 | Markup control                             | One control; change bars are the default markup.                                                                                                                                                                                                             | One markup control in the shell.                                                                                               |
| D22 | Size units in the template editor          | Type sizes are in points.                                                                                                                                                                                                                                    | None.                                                                                                                          |
| D23 | Word processor import                      | A native reader in the library's `./import` entry, with no third-party converter.                                                                                                                                                                            | A new `./import` entry.                                                                                                        |
| D24 | Cutover style                              | No data to move; the owner switches when ready.                                                                                                                                                                                                              | No migration work.                                                                                                             |
| D25 | Offline work                               | Full offline editing in both modes: room mode keeps a cached room state, store mode keeps drafts.                                                                                                                                                            | Offline support in both session modes, through host adapters.                                                                  |
| D26 | Stored versions                            | Named versions are stored document file snapshots, through the versions adapter.                                                                                                                                                                             | Versions are document files.                                                                                                   |

| D28 | Store mode conflicts                       | A three-way merge by element id, prompting only for blocks both sides changed.                                                                                                                                                                               | Merge in the store-mode session.                                                                                               |
| D29 | Where comments live in room mode           | In the same room, in separate top-level types. Commenters may write only the comment types.                                                                                                                                                                  | A room layout and write-rule recipe for room servers.                                                                          |
| D30 | Realtime binding                           | The library's own binding between the editor state and the shared document.                                                                                                                                                                                  | Hosts need no forked binding; a spike checks it on the current major version of the realtime library.                          |
| D31 | Word processor export                      | Faithful export at launch.                                                                                                                                                                                                                                   | A full document writer.                                                                                                        |
| D32 | Embedded field editor                      | No embedded field editor.                                                                                                                                                                                                                                    | None.                                                                                                                          |
| D33 | Switch-over                                | Library work only; the owner switches the first host when parity is sufficient.                                                                                                                                                                              | No migration, flags or rollback in the library.                                                                                |
| D34 | Print                                      | Printed output matches the editor's content and style exactly.                                                                                                                                                                                               | The library owns print rendering and its stylesheet; a per-page pixel comparison gates it.                                     |
